Barbershop Score — MusicXML import (experimental)

Choosing a MusicXML file loads it through the Kotlin engine (engine-kt) directly in the browser and immediately saves the chords into this browser's shared Score document — each row's "Edit" link then opens that chord in the full Chord-page editor (in a new tab), and edits there sync back here live (plan.md §10.2). "Export score" writes out the current state of the score, including any edits made via each row's "Edit" link (cents/vowel/notes) — it reflects whatever's currently saved in this browser's shared Score document, not necessarily the original file. Volume-per-part isn't wired up yet; whole-score playback isn't built yet either (plan.md §10.5).
